# Frontend Directory

This directory is ready for your **React + Vite** code generated by Figma/User.

## Instructions
1. Copy your React project files here (package.json, src/, public/, etc).
2. Install dependencies: `npm install`.
3. Configure your API calls to point to `http://localhost:5000/api`.

## Recommended API Integration
In your `ScannerView.tsx` (or similar):

```javascript
/* Capture frame from video element */
const captureFrame = () => {
    const canvas = document.createElement('canvas');
    canvas.width = videoRef.current.videoWidth;
    canvas.height = videoRef.current.videoHeight;
    canvas.getContext('2d').drawImage(videoRef.current, 0, 0);
    return canvas.toDataURL('image/jpeg'); // Returns base64 string
};

/* Send to Backend */
const recognizeFace = async () => {
    const imageBase64 = captureFrame();
    
    const response = await fetch('http://localhost:5000/api/recognize', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ image: imageBase64 })
    });
    
    const result = await response.json();
    console.log(result); // { recognized: true, name: "...", ... }
}
```
